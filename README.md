# Hawak Ko Ang Bit: The Final Bit

**Hawak Ko Ang Bit: The Final Bit** is a 2D pixel-style action game inspired by retro 8-bit arcade gameplay and modern digital-system themes. The game places the player inside a collapsing computer system where they must restore corrupted sectors, eliminate viruses, and recover the final surviving Bit that can reboot the entire system.

The game combines:

- Fast-paced enemy combat
- Retro pixel-art visuals
- Story-driven animated intros
- Multi-level progression
- Boss battles
- Timed gameplay mechanics
- Keyboard-based movement and attacks

The story takes place inside a damaged digital world where malware, corrupted data, and hostile system entities have taken over the computer’s core sectors.

The player progresses through:

1. Tutorial Sector
2. Boot Sector
3. Memory Core
4. System Kernel (Boss Level)

The game was developed using Java Swing and object-oriented programming principles.
